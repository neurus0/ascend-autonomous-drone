  ─────────────────────
  cd drone-GCS\backend
  npm install              (only first time)
  node server.js           (real mode — needs Jetson running)

  Then open browser: http://127.0.0.1:3000


  JETSON — LAUNCH FLIGHT STACK
  ──────────────────────────────
  roslaunch thl_drone unified_launch.launch fcu_url:=/dev/ttyACM0:115200


  DEPLOY FILES TO JETSON (from laptop)
  ──────────────────────────────────────
  scp jetson_unified/*.py jetson@192.168.70.108:~/catkin_ws/src/thl_drone/scripts/
  scp jetson_unified/*.launch jetson@192.168.70.108:~/catkin_ws/src/thl_drone/launch/
  ssh jetson@192.168.70.108 "chmod +x ~/catkin_ws/src/thl_drone/scripts/*.py"

    emergency_monitor.py Safety monitor
    photo_capture.py    Camera capture + logging

    vio_nav.py          Optical flow VIO

  launch/
    unified_launch.launch  Single launch file for all 7 nodes


================================================================================
  WHAT LAUNCHES (ORDER)
================================================================================

  1. MAVROS           — Pixhawk FCU bridge
  2. lidar_alt.py     — LiDAR altitude publisher
  3. vio_nav.py       — VIO navigation (3s delay)
  4. emergency_monitor.py — Safety (5s delay)
  5. tcp_bridge.py    — TCP server (3s delay)
  6. throttle_hover.py — Hover controller (8s delay)
  7. data_transfer.py — Data upload (5s delay)


================================================================================
  EMERGENCY PROCEDURES
================================================================================

  ▶ KILL (red button)     → Gradual throttle descent, LiDAR ground detect
  ⚡ DISARM (amber button) → IMMEDIATE motor cutoff (drone will DROP)
  Battery pull             → Last resort

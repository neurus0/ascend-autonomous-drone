# ASCEND System Architecture

## System Overview

ASCEND is an autonomous drone platform built around a companion-computer architecture. The system combines a Ground Control Station (GCS), an NVIDIA Jetson Nano companion computer, a Pixhawk flight controller, onboard sensors, and a communication layer based on MAVLink.

The architecture separates high-level processing from low-level flight control.

The Jetson Nano is responsible for running ROS-based software, managing communication, processing sensor data, and acting as the primary computing platform for autonomous drone experiments.

The Pixhawk flight controller is responsible for flight stabilization, state estimation, motor control, and execution of low-level flight commands.
 
Communication between the Ground Control Station, Jetson Nano, and Pixhawk is established using networking interfaces and MAVLink communication channels.

The system was developed and tested using both simulation and hardware-based workflows, including Gazebo simulation, SITL testing, and initial HITL/VTHL validation.

## Sensor Architecture

The ASCEND platform uses a distributed sensing architecture where sensors are connected either to the Jetson Nano companion computer or directly to the Pixhawk flight controller depending on their intended role within the system.

### Sensors Connected to the Jetson Nano

#### Logitech Camera

The Logitech camera is connected directly to the Jetson Nano and is accessible through the ROS software stack.

Its primary role is to provide visual data for computer vision experiments, perception tasks, and future autonomy-related development.

#### TF Mini Plus LiDAR

The TF Mini Plus LiDAR is connected to the Jetson Nano and provides distance measurements that can be accessed through ROS nodes.

The LiDAR data is available for environment sensing, altitude-related experiments, and future navigation development.

### Sensors Connected to the Pixhawk

#### PX4Flow Optical Flow Sensor

The PX4Flow sensor is connected directly to the Pixhawk flight controller.

The sensor provides ground-relative motion information that assists the flight controller in maintaining stable flight and position estimation.

#### Pixhawk IMU

The onboard IMU within the Pixhawk provides orientation and motion measurements required for flight stabilization and state estimation.

### Architecture Description

The Ground Control Station serves as the operator interface and communicates with the onboard computing system.

The Jetson Nano functions as the companion computer and hosts the ROS environment. It receives data from the Logitech camera and TF Mini Plus LiDAR while also managing communication with the flight controller through MAVLink.

The Pixhawk flight controller receives commands from the Jetson Nano and is responsible for low-level flight control tasks. It interfaces directly with the PX4Flow sensor and onboard IMU for flight-state estimation and stabilization.

Motor commands generated by the flight controller are transmitted to the ESCs, which regulate power delivery to the motors and produce the thrust required for flight.

---
This architecture separates high-level perception sensors from flight-critical stabilization sensors. The Jetson Nano acts as the primary processing platform for ROS-based sensing applications, while the Pixhawk manages sensors required for stable flight control.

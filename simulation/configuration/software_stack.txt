Useful ROS2 Commands
--------------------

Vehicle Position:
ros2 topic echo /fmu/out/vehicle_odometry | grep position -A 3

Sensor Data:
listener sensor_combined

Estimator Status:
listener estimator_status_flags

Repository Purpose
------------------
Development and testing environment for autonomous drone control,
simulation, sensor integration, offboard control, and qualification
tasks for the ISRO Robotics Challenge (IRoC-U 2026).
